\doxysubsection{Detailed Description}
\doxylink{class_driver}{Driver} for the left and right joint encoders. 

Handles initialization of both encoders and converts raw encoder counts into relative angular positions in degrees.

The first valid encoder position is treated as zero. Subsequent samples handle the 0–4095 rollover automatically.
